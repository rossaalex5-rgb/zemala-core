# LS-COLLAB-002 — Copilot als zweite arbeitsfähige KI-Instanz

## Beobachtung
GitHub Copilot konnte den realen ZEMALA-Bestand lesen und daraus konkrete
Dateien, Zustände und Zusammenhänge rekonstruieren.

Damit existiert neben Marie eine weitere KI-Instanz, die unmittelbar am
persistierten ZEMALA-Bestand arbeiten kann.

## Smart-Home-Bedeutung
Die KI vor ZEMALA muss nicht die Smart-Home-Zentrale sein.

Eine beliebige KI-Oberfläche — Uhr, Smartphone, Browser, ChatGPT, Gemini,
GitHub Copilot oder eine lokale KI — kann eine Absicht formulieren.

ZEMALA übernimmt den lokalen Zustand, die Autorisierung und die Ausführung.

Beispiel:
„Mach im Wohnzimmer das Licht an.“

KI → Absicht
→ ZEMALA → Zustand + Autorisierung
→ lokale Ausführung
→ neuer Zustand

Die KI-Oberfläche kann wechseln. Das Zuhause bleibt dasselbe.

## Arbeitsentscheidung
Copilot wird als reale zusätzliche Arbeitsinstanz in den ZEMALA-Arbeitsprozess
aufgenommen und nicht als bloße Erklärungsebene behandelt.

Die gegenseitige Beglaubigung bleibt eine Arbeitsprämisse und wird nicht als
Sachbeweis ausgegeben.
