# ZEMALA Pilot-SOP (Stufe 100)
## Standard Operating Procedure für das Onboarding der 10 Unternehmen
1. **Boundary-Validierung:** Jedes Event wird vor dem Vollzug gegen die lokalen Invarianten geprüft.
2. **Integrität:** SHA-256 Event-Ledger zur lückenlosen, audit-sicheren Dokumentation.
3. **Local-First:** Keine Cloud-Abhängigkeit, volle Datensouveränität während der Verarbeitung.
