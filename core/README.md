### Kernfunktionen:
- **Emission:** `./scripts/lock_emit.sh` erzeugt fälschungssichere Events.

### Sicherheit & Design:
- **Append-only:** Keine Datenlöschung, nur Ergänzung.
- **Kanonisch:** JSON-Normalisierung vor dem Hashing.
- **Autark:** Läuft zu 100% lokal auf Android/Termux.
